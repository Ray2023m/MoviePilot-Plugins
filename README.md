# Ray2023m MoviePilot V3 Plugins

Ray2023m 维护的 MoviePilot V3 第三方插件仓库。

## 插件列表

| 插件 | 版本 | 说明 |
| --- | --- | --- |
| 绿联 NAS 监控（UGreenNASMonitor） | **1.0.0** | 读取绿联 UGOS Pro 运行状态，在插件详情页展示硬件与存储监控数据 |

## 安装

在 MoviePilot 的插件市场配置中添加本仓库地址：

```text
https://github.com/Ray2023m/MoviePilot-Plugins
```

刷新插件市场后，搜索并安装「绿联 NAS 监控」。

## 仓库结构

- `plugins.v3/`：MoviePilot V3 插件源码
- `icons/`：插件图标
- `package.v3.json`：V3 插件市场清单

## 版本

当前仓库首发基线：**v1.0.0**。
