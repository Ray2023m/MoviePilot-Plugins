# Ray2023m MoviePilot V3 Plugins

第三方 MoviePilot V3 插件仓库。

## 插件列表

- **绿联 NAS 监控（UGreenNASMonitor）**：查看 UGOS Pro 的 CPU、内存、温度、风扇、磁盘、网络及存储卷状态。

## 安装市场

在 MoviePilot 的 `PLUGIN_MARKET` 配置中添加：

`https://github.com/Ray2023m/MoviePilot-Plugins`

然后刷新插件市场，安装「绿联 NAS 监控」。

## 目录

```text
plugins.v3/ugreennasmonitor/   # 插件源码与说明
icons/ugreennasmonitor.svg     # 插件图标
package.v3.json                # V3 插件市场索引
tests/v3/ugreennasmonitor/     # 基础测试
```
